# 滚动长截图（Chrome 扩展）

自动滚动网页并截图，拼接成一张长图。支持两种模式：

- **全屏滚动截图**：从页面顶部滚动到底部，截取整个页面。页面本身不滚动、而是内部容器滚动的（常见于后台系统、SPA、聊天页）会自动识别主滚动区域。
- **区域滚动截图**：先框选一块区域，扩展会从当前位置开始滚动该区域所在的滚动容器，只截取框选范围内的内容。框选时可以用滚轮先把页面滚到想开始的位置。

## 安装

有两种方式，任选其一。

### 方式一：拖入 .crx 安装包

1. 打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 把 `scroll-screenshot.crx` 拖进这个页面，在弹出的确认框里点「添加扩展程序」 https://github.com/jiangrenju/LongScreenshot/blob/main/out_put/scroll-screenshot.crx

> Chrome 正式版（Windows / macOS）会自动停用不是从应用商店安装的扩展。如果安装后显示「已停用」且无法开启，请改用方式二。360 极速浏览器、QQ 浏览器、Chrome 开发版 / Canary 等一般可以直接使用。

### 方式二：加载文件夹（任何 Chrome 都可用）

1. 把 `scroll-screenshot` 文件夹（或解压 `scroll-screenshot-1.0.0.zip` 得到的文件夹）放到固定位置，之后不要移动或删除
2. 打开 `chrome://extensions`，打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择这个文件夹   https://github.com/jiangrenju/LongScreenshot/blob/main/out_put/scroll-screenshot-1.0.0.zip

安装后，点地址栏右边的拼图图标 🧩，把「滚动长截图」固定到工具栏。

## 使用

- 点工具栏图标选择模式，或使用快捷键：
  - `Alt+Shift+F`（macOS 为 `Option+Shift+F`）：全屏滚动截图
  - `Alt+Shift+R`（macOS 为 `Option+Shift+R`）：区域滚动截图
  - 快捷键可以在 `chrome://extensions/shortcuts` 修改
- 截图过程中：`Enter` / 「完成」提前结束并拼接已截取的内容，`Esc` / 「取消」放弃
- 完成后会打开结果页，可以下载 PNG 或复制到剪贴板

## 设置（弹窗底部）

| 选项 | 说明 |
| --- | --- |
| 滚动间隔 | 每次滚动后等待渲染的时间。图片懒加载的页面选「慢速」 |
| 图片清晰度 | 「高清」按屏幕物理像素输出（Retina 屏为 2 倍）；「标准」按 1 倍输出，文件更小 |
| 隐藏悬浮 / 吸顶元素 | 第一屏之后隐藏 `position: fixed` 元素，并把 `sticky` 元素恢复为普通流，避免导航栏、悬浮按钮在长图里重复出现 |

## 限制

- `chrome://` 页面、扩展商店等浏览器保护的页面无法截图；本地 `file://` 页面需在扩展详情页开启「允许访问文件网址」
- 截图期间请保持该标签页在前台
- Chrome 限制每秒最多截屏 2 次，所以每屏约需 0.6 秒以上
- 单次最长约 60000 CSS 像素 / 200 屏；超出单张画布上限（32000 像素）时会自动按顺序拆成多张图片
- iframe 内部的滚动内容不会被滚动
- 仅保留最近 10 次截图结果
